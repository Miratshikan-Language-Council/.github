# Слэварако̀нзил Мирачиканы
### Miratshikan Language Council
The Miratshikan Language Council (SKM) is an independent project dedicated to the documentation, development, and standardization of the Miratshikan language.

## About
The Miratshikan Language Council is a community organization concerned with the development of Miratshikan, including its vocabulary, grammar, orthography, phonology, and more.

The Miratshikan Language Council maintains and develops resources intended to provide a consistent reference to the language.

## Disclaimer
The Miratshikan Language Council is an independent, non-governmental language project. It has no official governmental, legal, academic, or institutional authority.

References to a "council", "standard", "official", "approved", or similar terminology within this project describe the internal organization and conventions of the Miratshikan project unless explicitly stated otherwise.
